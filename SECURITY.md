# Security

If you find a security problem in this plugin or in the My Fordyce service it connects to, please email **support@fordycecg.com** with "Security" in the subject line. Please don't open a public issue for it.

Include what you found, the steps to reproduce it, and what it could affect.

## Scope

This repository holds instructions and configuration only. The plugin runs no local code: it declares one remote MCP server at https://myfordyce.fordycecg.com, and its skills are plain instructions for Claude.
